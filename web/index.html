HOW IT WORKS

  1. 01解析变更提取变更文件与新增代码行。
  2. 02协作审查Lead 委派任务，Worker 提供证据，Critic 复核候选。
  3. 03验证与筛选格式、证据、置信度与发布门禁。
  4. 04报告与反馈查看结论；你的反馈可进入后续演进评测。
